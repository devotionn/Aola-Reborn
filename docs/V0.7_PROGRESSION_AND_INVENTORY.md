# Aola-Reborn v0.7 Progression & Inventory

## Goal

本轮把 v0.6 的“PP + 状态战斗”继续推进成真正可持续的养成系统：星灵拥有个体技能栏、升级可学习新技能、四技能满时由玩家决定替换；同时建立正式背包、PP 恢复经济，并开放第三调查区的可玩前置探索。

## Implemented

### 1. 个体技能栏

`CreatureInstance` 新增：

- `moveIds`：这只星灵当前实际掌握的最多 4 个技能
- `pendingMoveIds`：达到学习条件、但尚未完成替换的新技能
- `movePp`：继续跟随个体技能栏保存 PP

物种的 `moveIds` 现在作为初始技能模板，不再决定这只星灵一生固定只能使用哪四招。

旧存档读取时会自动：

1. 从当前物种模板补齐个体技能栏；
2. 初始化缺失 PP；
3. 根据当前等级检查应当解锁但尚未学习的技能；
4. 保留 LocalStorage `version: 1`，无需删档。

### 2. 等级技能学习与玩家替换

`Species` 新增数据驱动 `learnset`。

首批学习路线：

- 曜焰灵 Lv.12 → **星焰扑击**
- 沧澜兽 Lv.12 → **深澜回流**
- 森冠狸 Lv.12 → **森冠棘环**
- 晶露蜗 Lv.11 → **月潮**

当技能栏不足 4 招时，新技能可以直接加入；技能栏已满时，新技能进入 `pendingMoveIds`。

新增 `MoveLearnScene`：

- 显示待学习技能的属性、威力、PP、状态概率与说明；
- 同时展示当前四个技能；
- 鼠标点击或 `1`–`4` 选择要忘记的技能；
- 替换后新技能获得完整初始 PP；
- `Esc` 可以暂缓处理，新技能不会丢失；
- 主城 / 星落原野 / 烬苔林地 / 雾镜湿地均可按 `L` 处理队首的待学习技能。

战斗胜利升级时，如果本次解锁了需要替换的新技能，会在结算后自动进入技能学习界面。

### 3. NPC PP 耗尽保底行为

NPC 不再在四个技能 PP 全部耗尽后无限使用 0 PP 技能。

新增保底行动：

**余辉震荡 / strugglePulse**

- 星系 / 中性
- 低威力
- 100% 命中
- 仅作为常规技能全部耗尽时的 NPC 兜底行为

这使 PP 对玩家和 NPC 都真正参与长期战斗资源管理。

### 4. 正式探索背包

新增 `BagScene`。

全局主要探索场景统一：

- `B` → 打开背包
- `L` → 处理待学习技能
- `H` → 快速使用星辉恢复剂

背包当前支持：

#### 星辉恢复剂

- 恢复当前队首约 45% 最大 HP
- 清除当前异常状态

#### 星能补充剂

- 恢复当前队首四个技能约 50% 最大 PP
- 只有存在 PP 缺口时才会消耗

#### 捕捉胶囊

- 背包显示数量
- 继续只在允许捕捉的战斗中使用

背包同时展示当前队首：

- HP
- 状态
- 四个技能的实时 PP

### 5. 补给经济扩展

`FacilitySystem` / `FacilityScene` 新增：

**星能补充剂**

- 研究站 / 公共设施可重复购买
- 当前费用：110 星币 / 个

设施现在形成：

- 捕捉胶囊补给
- 星辉恢复剂补给
- 星能补充剂补给
- 队首训练

训练继续复用正式经验 / 成长 / 技能学习流水线，因此通过训练达到技能学习等级同样会产生待学习技能。

### 6. 烬苔林地第二只独占星灵

新增：

**晶露蜗 / crystalDewSnail**

- 水系
- 高 HP / 高专注 / 低速度
- 栖息在晶湖湿润岩面
- 当前只进入烬苔林地与后续湿地区域生态
- Lv.11 可尝试学习月潮

至此烬苔林地已经拥有两只明确区域特色星灵：

- 苔灯蛾
- 晶露蜗

### 7. 第三调查区前置探索：雾镜湿地

新增标准 Tiled Object Map：

`src/game/maps/mist-wetland.json`

新增场景：

`MistScene`

区域包含：

- `Barriers`：泥沼、镜池、芦苇障碍
- `EncounterZones`：银芦浅滩、雾岸草洲
- `Points`：返回门、雾镜信标
- 独立更高等级遭遇区间
- 独立区域遭遇池
- B / L / H 全局操作

解锁路径：

```text
星港
  ↓
星落原野第一调查
  ↓
烬苔林地第二调查
  ↓
第二调查奖励领取
  ↓
北侧雾门解锁
  ↓
雾镜湿地
```

当前雾镜湿地是**第三调查区的可玩前置探索骨架**，不是完整第三任务线。

玩家可完成一次“雾镜信标初次记录”：

- 写入 `mistBeaconSurveyed`
- 星币 +160
- 星能补充剂 +1

完整第三调查 NPC、特殊挑战和区域主线留到下一阶段继续。

## Rule coverage

现有 Vitest 继续覆盖 v0.6 规则，并新增：

- Lv.12 新技能进入待学习队列
- 满 4 技能时不会静默覆盖旧技能
- 指定技能位替换成功
- 替换后待学习记录清除
- NPC 所有常规技能 PP 耗尽时使用余辉震荡
- 星能补充剂恢复 PP 并正确消费库存

## Known gaps

以下内容本轮没有伪装成已完成：

1. 当前只有首批等级技能学习路线，尚未建立大规模等级技能表。
2. 背包道具目前默认作用于队首，尚未提供“选择任意队员使用”的完整 UI。
3. 星能补充剂目前主要通过探索背包使用，战斗内尚未增加 PP 道具按钮。
4. `余辉震荡` 当前是 NPC PP 耗尽保底；玩家四招全空时仍需要换宠或退出恢复，尚未开放玩家主动挣扎行动。
5. 雾镜湿地当前是第三调查区前置骨架，不是完整第三任务线。
6. 仍只有 `scorch` / `sluggish` 两种异常状态。
7. 尚未加入物理/特殊/变化技能分类、能力阶段变化、天气或场地系统。
8. Tiled 目前仍以 Object Layer 为主，正式 tileset / tile layer 美术尚未进入生产管线。
9. Phaser 主 bundle 仍有 >500 kB warning，后续需要 code splitting。
10. Playwright 端到端流程测试尚未加入。
