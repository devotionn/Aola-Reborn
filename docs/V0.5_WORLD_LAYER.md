# Aola-Reborn v0.5 World Layer

## Goal

把项目从“主城 + 单张野外地图”的纵切，推进为可持续扩展的多区域世界层：地图数据、实体碰撞、连续任务、区域遭遇、设施经济和旧存档兼容开始进入同一套框架。

## Implemented

### 1. 第二调查区：烬苔林地

- 新场景 `GroveScene`
- 第一调查任务完成后，星落原野北侧远星门解锁
- 星落原野与烬苔林地可双向切换
- 第二调查区拥有独立遭遇池与更高等级区间
- 新剧情 NPC：巡林员 · 柏舟
- 第二条完整调查任务：交谈 → 检查星纹石 → 特殊挑战 → 汇报 → 奖励
- 任务状态继续使用 LocalStorage flags 持久化

### 2. Tiled Object Layer 地图管线

新增标准 Tiled JSON：

`src/game/maps/ember-grove.json`

对象层约定：

- `Barriers`：不可穿越区域
- `EncounterZones`：随机遭遇区域
- `Points`：NPC、任务点、传送点

新增 `ObjectMapSystem`：

- 查找对象层
- 查找命名对象
- 点位包含判断
- 角色半径碰撞判断

烬苔林地目前已经让晶湖、岩壁和树林参与实体碰撞。地图对象可继续在 Tiled 中编辑，而不需要把全部坐标重新写进场景代码。

### 3. 星港设施与经济

新增 `FacilityScene` 与 `FacilitySystem`。

当前服务：

- 捕捉胶囊补给：消耗星币获得胶囊
- 星辉恢复剂补给：消耗星币写入库存
- 队首训练：消耗星币获得 EXP

训练复用正式 `grantExp` / 成长流水线，因此训练升级也能触发 Lv.10 成长形态，并同步发现记录。

### 4. 存档兼容

`PlayerSave` 新增可选 inventory。

旧存档读取时会自动补：

```ts
inventory: { tonics: 0 }
```

同时自动补齐 flags，避免 v0.4 存档因为新增字段失效。

### 5. 主城入口修正

本轮同时修正了上轮已存在但未完整接入主城的入口：

- `G` → 星灵手册
- `T` → 伙伴编组
- 星灵仓库按 `E` → 完整编组
- 研究站首批补给领取后 → 常规设施服务
- 训练场按 `E` → 设施服务
- `P` 继续保留轻量队伍 / 仓库快览

## Current world loop

```text
星港
  ↓
星落原野
  ↓ 第一调查
曜角鹿特殊挑战
  ↓
远星门解锁
  ↓
烬苔林地
  ↓ 第二调查
星纹石特殊挑战
  ↓
任务奖励 / 继续区域收集
```

同时主城侧形成：

```text
战斗 / 捕捉
  ↓
星币 / EXP
  ↓
补给 / 训练
  ↓
成长 / 编组 / 手册
  ↓
更远区域探索
```

## Known gaps

这些内容本轮没有伪装成“已完成”：

1. 星落原野仍是场景内坐标绘制，尚未迁移到 Tiled Object Map。
2. 恢复剂已经进入 inventory 和规则层，但野外 / 对局快捷使用 UI 还未完整接入。
3. 烬苔林地目前复用现有星灵作为区域遭遇池，独占原创星灵下一阶段补。
4. 特殊对局的标题仍需要进一步按区域参数化。
5. Phaser 主 bundle 仍有 >500 kB warning，后续做场景动态加载和 code splitting。
6. 地图几何与设施经济的独立 Vitest 文件写入被当前 GitHub 安全层误拦；现有规则测试与完整 CI 仍正常运行。
