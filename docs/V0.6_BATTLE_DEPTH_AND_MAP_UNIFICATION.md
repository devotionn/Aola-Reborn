# Aola-Reborn v0.6 Battle Depth & Map Unification

## Goal

本阶段把 v0.5 的多区域探索骨架进一步收敛为统一世界模型，并让对局从“4 技能 + HP”进入具有资源管理与异常状态的策略层。

重点不是继续堆地图数量，而是让现有两张野外地图、存档、战斗、补给与图鉴围绕同一套数据规则运行。

## Implemented

### 1. 星落原野迁移到 Tiled Object Map

新增：

`src/game/maps/starfall-field.json`

星落原野与烬苔林地现在都使用相同对象层协议：

- `Barriers`：不可穿越区域
- `EncounterZones`：随机遭遇区域
- `Points`：NPC、任务点、回城门、远星门等

星落原野不再依赖场景内部硬编码的草地区域 / NPC / 祭坛 / 门坐标进行核心判定。

运行时继续由 `ObjectMapSystem` 提供：

- `objectsInLayer`
- `findObject`
- `containsPoint`
- `collidesWithAny`

两张野外地图因此开始共享同一套地图数据模型。

### 2. 技能 PP

所有技能新增 `pp` 配置。

设计原则：

- 基础技能 PP 较高
- 中等威力技能 PP 居中
- 高威力 / 高异常收益技能 PP 更低

`CreatureInstance` 新增可选 `movePp`，旧 v0.5 存档在读取时自动补齐 PP，不需要删档。

新增规则：

- `ensureMovePp`
- `remainingPp`
- `spendMovePp`
- `restoreMovePp`

恢复中心会同时恢复 HP、清除异常状态并补满技能 PP。

成长形态切换后会按照新形态技能组重新初始化 PP。

### 3. 异常状态

当前首批异常状态：

#### 灼热 scorch

- 回合结束扣除约最大 HP 6%
- 持续指定回合数

#### 迟缓 sluggish

- 有效速度降低到约 75%
- 持续指定回合数

技能配置可以通过：

```ts
condition: {
  type,
  chance,
  turns
}
```

声明异常效果，不需要在 BattleScene 为每个技能写独立判断。

首批火 / 水 / 草 / 电技能已经接入异常概率。

### 4. 战斗内恢复剂

战斗中新增：

`H` → 使用星辉恢复剂

效果：

- 恢复约最大 HP 45%
- 清除当前异常状态
- 消耗 1 个库存恢复剂
- 使用道具会让对方获得一次行动机会

因此恢复剂不是无成本暂停按钮，而是正式进入回合资源决策。

星落原野和烬苔林地同样支持 `H` 快捷使用恢复剂。

### 5. 区域化特殊对局

`BattleRequest` 新增：

- `battleTitle`
- `battleSubtitle`
- `captureBlockedMessage`

因此特殊对局不再固定显示“星落原野 · 守护挑战”。

当前：

- 曜角鹿：`星落原野 · 古星祭坛`
- 岩壳龟共鸣个体：`烬苔林地 · 晶湖星纹石`

两者拥有不同标题、副标题和不可捕捉提示。

### 6. 烬苔林地首只独占星灵

新增原创区域星灵：

**苔灯蛾 / mossLanternMoth**

定位：

- 木系
- 高速度 / 偏输出
- 只进入烬苔林地遭遇池
- 技能组合包含草系与星纹相关技能

星灵手册总记录数会随之增加。

### 7. 星灵手册补充战斗信息

技能详情现在展示：

- 属性
- 威力
- PP 上限
- 技能描述
- 若存在异常状态：异常概率与异常名称

玩家不需要进入战斗后才知道技能资源与异常特征。

## Save compatibility

当前仍保持：

`version: 1`

新增字段均采用兼容式读取：

- `inventory` 缺失 → 自动补默认库存
- `flags` 缺失 → 自动补空对象
- `movePp` 缺失 → 按当前星灵技能组补满

因此 v0.4 / v0.5 本地 LocalStorage 存档可以继续使用。

## Rule coverage

现有 Vitest 在原有成长 / 捕捉 / 属性关系基础上新增：

- PP 初始化与消耗
- PP 不会进入负数
- 迟缓会降低有效速度
- 灼热会扣除 HP
- 灼热持续时间结束后会自动清除

production build 仍通过：

```text
vitest run → tsc --noEmit → vite build
```

## Current game loop

```text
探索 Tiled 地图
  ↓
区域遭遇
  ↓
选择技能 + 管理 PP
  ↓
属性克制 / 灼热 / 迟缓
  ↓
换宠 / 捕捉 / 恢复剂
  ↓
EXP / 星币 / 成长
  ↓
补给 / 训练 / 编组 / 手册
  ↓
继续区域任务和收集
```

## Known gaps

以下内容仍明确列为后续工作，不计入 v0.6 已完成范围：

1. NPC 在 PP 全耗尽时还没有专门的“挣扎”技能，目前会回退到原技能池。
2. 异常状态目前只有灼热和迟缓，还没有中毒、睡眠、控制抗性等更完整状态体系。
3. PP 尚未接入单独的恢复道具；目前主要依靠恢复中心补满。
4. 对局视觉仍为几何占位表现，尚未接正式星灵立绘和技能动画。
5. Tiled 当前主要使用 Object Layer，还没有正式 tileset / tile layer 美术地图。
6. 第三调查区尚未开发。
7. Phaser 主 bundle 的 >500 kB warning 仍待 code splitting 处理。
8. 浏览器端到端 Playwright 核心流程仍待补充。

## IP boundary

`Aola` 继续仅作为开发阶段 repo 代号。公开发行或商业化前应完成原创品牌替换，并保持角色、星灵、美术、地图、剧情、音乐和 UI 资产原创。
