# Aola-Reborn

一个面向 PC 浏览器的怀旧宠物收集 RPG 原型。目标是复现童年网页宠物养成游戏的节奏与乐趣，同时使用原创名称、原创数据、原创世界观和自有美术资产。

## 当前里程碑：v0.3 field quest slice

项目已经从单地图技术原型进入“主城 + 野外 + 任务 + 守护挑战”的 RPG 纵切阶段。

### 核心循环

- 三选一初始伙伴
- 星港广场自由探索
- 星门前往第一张正式野外地图「星落原野」
- 草地区域随机遭遇
- 每只星灵 4 技能
- 正式 HP 对局、命中率、速度先后手与属性倍率
- 动态捕捉概率：剩余 HP 越低越容易建立连接
- 战斗 EXP、升级与星币奖励
- 捕捉后进入四人队伍或星灵仓库
- LocalStorage 保存队伍、资源、地图位置和任务状态

### v0.3 新增

- 第一张独立野外地图：**星落原野**
- 主城星门与野外地图双向切换
- 可复用 `DialogueBox` NPC 对话组件
- 第一位剧情 NPC：**研究员 · 岚音**
- 第一条完整调查任务链：接取 → 调查祭坛 → 守护对局 → 回报 → 奖励
- 第一只守护型原创星灵：**曜角鹿**
- 守护对局不可捕捉，胜利后写入任务完成 flag
- 普通野外对局结束后返回原野，不再统一传送到主城
- 技能影响数字浮动反馈
- 属性优势时增加镜头震动反馈
- 任务奖励：星币与捕捉胶囊
- 原创技能配置扩展到 18 个

### 星港系统

- 研究站首次补给
- 星辉恢复中心
- 星灵仓库浮层
- 队首切换
- 草地测试遭遇

## 操作

**初始伙伴**：`1` / `2` / `3`

**星港广场**：

- `WASD` / 方向键：移动
- `E`：与附近设施或星门交互
- `P`：打开 / 关闭星灵仓库
- `1`–`4`：仓库界面中切换队首
- `R`：触发开发测试遭遇
- `Esc`：关闭浮层

**星落原野**：

- `WASD` / 方向键：移动
- `E`：与研究员、古星祭坛和出口交互
- `Space`：对话时继续
- `Esc`：返回星港
- 原野两侧草地区域会随机出现星灵

**普通对局**：

- `1`–`4`：使用技能
- `C`：使用捕捉胶囊
- `Esc`：返回进入对局前的区域

守护任务对局中不可使用捕捉功能。

## 技术栈

- TypeScript
- Phaser 4.2.1
- Vite 8
- Browser LocalStorage
- GitHub Actions

## 启动

```bash
npm install
npm run dev
```

验证：

```bash
npm run typecheck
npm run build
npm run preview
```

GitHub Actions 会在 push / pull request 时自动执行依赖安装、TypeScript typecheck 和 production build。

## 结构

```text
src/game/
├─ data/       # 星灵、技能、属性配置
├─ scenes/     # Boot / Starter / World / Wild / Battle
├─ state/      # 本地存档
├─ systems/    # 对局、捕捉与成长规则
├─ ui/         # 可复用对话等 UI 组件
├─ config.ts
└─ types.ts
```
