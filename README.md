# Aola-Reborn

一个面向 PC 浏览器的怀旧宠物收集 RPG 原型。目标是复现童年网页宠物养成游戏的节奏与乐趣，同时使用原创名称、原创数据、原创世界观和自有美术资产。

## 当前里程碑：v0.4 collection & roster slice

项目已经形成“主城 → 野外 → 遭遇/捕捉 → 任务守护战 → 队伍编组 → 成长形态 → 手册记录”的完整单机养成纵切。

### 核心循环

- 三选一初始伙伴
- 星港广场自由探索
- 星门前往第一张正式野外地图「星落原野」
- 草地区域随机遭遇
- 每只星灵 4 技能
- 正式 HP 对局、命中率、速度先后手与属性倍率
- 动态捕捉概率：剩余 HP 越低越容易建立连接
- 战斗 EXP、升级与星币奖励
- 捕捉后进入四人队伍或星灵仓库
- LocalStorage 保存队伍、资源、地图位置和任务状态

### v0.4 新增

- **星灵手册 `FieldGuideScene`**：显示发现进度、属性、基础能力、技能说明与成长路线
- 未发现星灵保持隐藏，不提前泄露资料
- **伙伴编组 `RosterScene`**：队伍与仓库双向调配
- 非队首伙伴可存入仓库，仓库伙伴可重新加入未满的队伍
- 队首可在编组界面通过点击或 `1`–`4` 调整
- **对局内换宠**：按 `Q` 打开伙伴选择
- 主动换宠会给予对方一次行动机会
- 当前伙伴倒下后，只要队伍仍有可用伙伴就自动接替
- 全队没有可用伙伴时才执行撤回逻辑，避免单只倒下等于整队失败
- 第一套数据驱动成长系统
- 三个初始伙伴在 **Lv.10** 分别成长为 **曜焰灵 / 沧澜兽 / 森冠狸**
- 成长后自动刷新能力、技能展示，并把新形态加入发现记录
- 新增 Vitest 规则测试，覆盖成长触发、捕捉概率边界与属性关系
- `npm run build` 会先执行规则测试，再进行 TypeScript 检查和 Vite production build

### v0.3 已有内容

- 第一张独立野外地图：**星落原野**
- 主城星门与野外地图双向切换
- 可复用 `DialogueBox` NPC 对话组件
- 第一位剧情 NPC：**研究员 · 岚音**
- 第一条完整调查任务链：接取 → 调查祭坛 → 守护对局 → 回报 → 奖励
- 第一只守护型原创星灵：**曜角鹿**
- 守护对局不可捕捉，胜利后写入任务完成 flag
- 普通野外对局结束后返回原野，不再统一传送到主城
- 技能影响数字浮动反馈与属性优势镜头反馈

### 当前内容量

- 10 种原创星灵形态，其中 3 种为成长形态、1 种为任务守护星灵
- 6 种属性
- 18 个原创技能配置
- 4 技能对局框架
- 1 个主城、1 张独立野外地图、1 条完整任务链

## 操作

**初始伙伴**：`1` / `2` / `3`

**星港广场**：

- `WASD` / 方向键：移动
- `E`：与附近设施或星门交互
- `P`：打开 / 关闭仓库快览
- `G`：打开星灵手册
- `T`：打开伙伴编组
- `1`–`4`：仓库快览中切换队首
- `R`：触发开发测试遭遇
- `Esc`：关闭浮层

**星灵手册**：

- `W` / `S` 或方向键：切换记录
- 鼠标：点击星灵条目
- `G` / `Esc`：返回星港

**伙伴编组**：

- 鼠标：设置队首、存入仓库、从仓库加入队伍
- `1`–`4`：设置队首
- `T` / `Esc`：返回星港

**星落原野**：

- `WASD` / 方向键：移动
- `E`：与研究员、古星祭坛和出口交互
- `Space`：对话时继续
- `Esc`：返回星港
- 原野两侧草地区域会随机出现星灵

**普通 / 守护对局**：

- `1`–`4`：使用技能
- `Q`：更换上场伙伴
- `C`：使用捕捉胶囊（守护任务对局不可捕捉）
- `Esc`：关闭换宠面板或返回进入对局前的区域

## 技术栈

- TypeScript
- Phaser 4.2.1
- Vite 8
- Vitest 4
- Browser LocalStorage
- GitHub Actions

## 启动

```bash
npm install
npm run dev
```

验证：

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

`npm run build` 当前会执行：

```text
vitest run → tsc --noEmit → vite build
```

GitHub Actions 会在 push / pull request 时自动安装依赖、执行 TypeScript typecheck，并运行包含规则测试的 production build。

## 结构

```text
src/game/
├─ data/       # 星灵、技能、属性与成长配置
├─ scenes/     # Boot / Starter / World / Wild / Battle / FieldGuide / Roster
├─ state/      # 本地存档
├─ systems/    # 对局、捕捉、经验与成长规则 + 单元测试
├─ ui/         # 可复用对话等 UI 组件
├─ config.ts
└─ types.ts
```
