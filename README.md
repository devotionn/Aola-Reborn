# Aola-Reborn

一个面向 PC 浏览器的怀旧宠物收集 RPG 原型。目标是复现童年网页宠物养成游戏的节奏与乐趣，同时使用原创名称、原创数据、原创世界观和自有美术资产。

## 当前里程碑：v0.2 playable slice

已经形成可持续扩展的核心循环：

- 三选一初始伙伴
- 星港广场探索
- WASD / 方向键移动
- 草地区域随机遭遇，`R` 可触发开发测试遭遇
- 6 种原创星灵、6 种属性、16 个技能
- 每只星灵 4 技能
- 正式 HP 对局、命中率、速度先后手与属性倍率
- 敌我 HP 条、经验进度、技能面板
- 动态捕捉成功率：星灵剩余 HP 越低越容易建立连接
- 捕捉胶囊、四人队伍与星灵仓库数据
- 战斗 EXP、升级、星币奖励
- 研究站首次补给
- 星辉恢复中心
- 主城仓库浮层、队首切换
- LocalStorage 本地存档与地图位置保存
- GitHub Actions 自动执行 typecheck 与 production build

## 操作

**初始伙伴**：`1` / `2` / `3`

**星港广场**：

- `WASD` / 方向键：移动
- `E`：与附近设施交互
- `P`：打开 / 关闭星灵仓库
- `1`–`4`：仓库界面中切换队首
- `R`：触发开发测试遭遇
- `Esc`：关闭浮层

**野生对局**：

- `1`–`4`：使用技能
- `C`：使用捕捉胶囊
- `Esc`：撤回星港

## 启动

```bash
npm install
npm run dev
```

验证：

```bash
npm run typecheck
npm run build
npm run preview
```

## 结构

```text
src/game/
├─ data/       # 星灵、技能、属性配置
├─ scenes/     # Boot / Starter / World / Battle
├─ state/      # 本地存档
├─ systems/    # 对局、捕捉与成长规则
├─ config.ts
└─ types.ts
```
