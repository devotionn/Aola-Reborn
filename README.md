# Aola-Reborn

一个面向 PC 浏览器的 **怀旧宠物收集 / 回合制战斗 Web Game 原型**。

项目目标是复现 2010 年代中文宠物页游的核心体验：选伙伴、逛地图、随机遭遇、回合战斗、捕捉、升级、图鉴与任务循环。项目不会直接复制既有商业游戏的角色、美术、剧情、音乐、地图或其他受保护素材；当前星灵、技能和视觉均为原创占位内容。

## 当前可玩内容（v0.1 vertical slice）

- 三选一初始星灵：炽尾团子 / 澜鳍兽 / 森芽狸
- 星港广场探索地图
- WASD / 方向键移动
- 草地区域随机遭遇，`R` 可强制触发遭遇方便测试
- 6 种原创星灵，6 种属性
- 数据驱动技能与属性克制
- 速度判定、命中、伤害浮动、暴击、属性倍率
- 野生星灵捕捉与 HP 越低成功率越高
- 等级、经验、队伍 / 仓库雏形
- `localStorage` 本地存档
- 当前使用几何图形 + 文本作为视觉占位

## 技术栈

- TypeScript
- Phaser 4.2.1
- Vite 8
- 浏览器 LocalStorage（MVP 存档）

## 下一阶段建议

1. 地图系统化：Tiled 地图、碰撞层、传送点、NPC、交互触发器。
2. 星灵系统：属性成长、技能学习、进化、性格 / 天赋可选层。
3. 战斗 v2：PP、状态效果、换宠、道具、完整战斗状态机、AI 策略。
4. 内容循环：任务、Boss、图鉴、商店、恢复站、捕捉区域。
5. 视觉资产：原创 2D 星灵立绘、地图 tileset、角色 sprite、战斗动画。
6. 后端化：账号、云存档、好友、PVP / 排行榜再独立进入服务端阶段。

## 设计原则

- 先做到“5 分钟完整循环”：选伙伴 → 出发 → 遭遇 → 战斗 → 捕捉 / 升级 → 回城。
- 数据驱动优先：新增星灵和技能不修改核心战斗流程。
- 玩法和内容解耦：未来可以整体替换世界观与美术，不推翻游戏系统。
- 先单机验证乐趣，再做联网。
